# 可轉債折溢價追蹤器

## 快速開始

### 1. 安裝 Python（3.9+）
前往 https://python.org 下載並安裝

### 2. 安裝依賴
```
cd C:\Users\a4s5d\cb-tracker
pip install -r backend\requirements.txt
```

### 3. 啟動
雙擊 `start.bat`，或在命令提示字元執行：
```
python -m uvicorn backend.main:app --port 8000 --reload
```

### 4. 開啟瀏覽器
前往 http://localhost:8000

## 使用方式

### 第一次使用
1. 點「新增CB」手動加入可轉債，填入：CB代號、CB名稱、股票代號、轉換價格
2. 或點「更新資料」→ 系統自動從 mis.twse.com.tw 抓取已存在CB的報價
3. 轉換價格（轉換價）很重要，沒有它就無法計算折溢價

### 折溢價顏色說明
| 顏色 | 含義 |
|------|------|
| 深綠 | 深度折價 < -10% （CB便宜，相對股票更划算）|
| 淺綠 | 折價 < 0% |
| 灰色 | 接近平價 |
| 黃色 | 輕微溢價 |
| 橘紅 | 溢價 > 10% |
| 深紅 | 高溢價 > 20% （CB貴，有轉換空間但價格高）|

### 折溢價計算公式
```
平價 = 股價 × (100 ÷ 轉換價格)
折溢價% = (CB現價 - 平價) / 平價 × 100%
```

範例：股價50元，轉換價45元，CB現價110元
- 平價 = 50 × (100/45) = 111.11
- 折溢價 = (110 - 111.11) / 111.11 × 100% = **-1.0%（折價）**

## 常見CB代號格式
- TWSE上市可轉債：5位數字，如 `23303`（2330的第3次可轉債）
- TPEX上櫃可轉債：同樣5位數字

## 資料來源
- CB報價：mis.twse.com.tw
- 股票報價：openapi.twse.com.tw / tpex.org.tw
- 轉換價格：需手動輸入，或嘗試自動從MOPS抓取
